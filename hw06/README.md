# HW6: DAX Measure Library (hw06)

## Notes on the Measures report page

The four summary measures (`Ending AUM`, `Ending Clients`, `Avg AUM per Client`,
`Top 10 Client Share`) are shown as one single-measure table each, not as card visuals.
In the Apporto Power BI Desktop session, card and KPI visuals displayed blank, even
after recreating them, trying a new page, and restarting Power BI. Table visuals and
DAX query view returned the correct values for the same measures, so the measures
themselves are not affected. Only the visual type was changed.
